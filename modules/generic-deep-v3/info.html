通用 · deep-fingerprint-v3

采集参数

深度浏览器指纹基线 v3：environment 快照 32 组 + deepProbes 谎言检测三层（queryLies 10 接口 ~20 项检查 / prototypeLies 40+ 接口递归 / phantomIframe 对比 / 双画布稳定性 / plugins-mimeTypes 交叉验证）+ trash 乱码检测 + resistance（timer precision/RFP/Brave/Tor/扩展哈希）。行为指纹走独立行为采集页。机制参考 CreepJS (MIT)，自写实现。

参数说明

  • navigator —— 浏览器与设备属性：UA、平台、语言、硬件并发、插件集合等 20+ 字段。
    作用：识别浏览器类型、操作系统与基础硬件配置；UA 与多字段交叉一致性的基础数据。
  • screen —— 屏幕分辨率、可用区域与色深。
    作用：识别显示设备规格；与视口数据交叉验证分辨率伪装。
  • viewport —— 视口尺寸、设备像素比与窗口偏移。
    作用：识别浏览器窗口状态；DPR 与分辨率组合是设备指纹的稳定分量。
  • webgl —— WebGL 18 项参数与 UNMASKED 渲染器标识。
    作用：GPU 型号与驱动指纹；渲染器品牌分级判定伪造。
  • webgl2 —— WebGL2 参数面（可用时）。
    作用：GPU 能力指纹的扩展维度。
  • offscreen —— OffscreenCanvas 支持与上下文类型。
    作用：浏览器版本能力面指纹。
  • timing —— 导航时序关键点（浅层）。
    作用：页面加载性能特征。
  • matchMedia —— 9 组媒体查询响应（断点/配色/指针/悬停）。
    作用：显示设备与浏览器偏好指纹。
  • cssom —— CSS 特性支持与样式系统行为（:focus-within/宽色域/cssRules）。
    作用：浏览器渲染引擎版本指纹；cssRules 可访问性反映安全上下文。
  • storage —— localStorage/sessionStorage 读写往返与 indexedDB 可用性。
    作用：存储可用性指纹；隐私模式下读写失败是重要特征。
  • intl —— 国际化环境：时区、日历、数字系统、区域设置。
    作用：系统区域指纹；时区与 IP 地理位置的交叉验证基础。
  • fonts —— 常用字体可用性（9 组布尔探测）。
    作用：字体集合指纹的基础维度。
  • apiSurface —— 22 项 Web API 存在性矩阵（电池/权限/WebXR/串口等）。
    作用：浏览器版本与功能面指纹；缺失项反映隐私策略或伪装。
  • prototypeProbes —— 原型行为探测：hasFocus/setProperty 描述符与 String receiver 行为。
    作用：检测原型篡改：原生函数行为异常是自动化环境的主要特征。
  • pluginsDeep —— 插件集合深度行为（item/namedItem/首插件详情）。
    作用：插件体系指纹与集合一致性验证。
  • fontsMeasure —— 10 组字体字形测量宽度。
    作用：字体渲染指纹：同一字体在不同系统上的度量差异。
  • automationFlags —— 自动化痕迹：webdriver 描述符、CDP/Selenium 遗留属性、headless UA。
    作用：自动化环境检测：无头浏览器与驱动注入的直接证据。
  • timingDeep —— 导航时序全 21 字段、资源与绘制条目计数。
    作用：加载行为特征；与声明环境的一致性交叉点。
  • webrtc —— RTCPeerConnection 与数据通道行为。
    作用：WebRTC 能力指纹；可用于后续网络面扩展。
  • cookieHistory —— Cookie 写读往返、历史记录长度与窗口关系。
    作用：存储与导航状态指纹；窗口关系反映嵌入场景。
  • media —— 语音合成/识别与 MediaSource 能力。
    作用：媒体能力面指纹。
  • wasm —— WebAssembly 内存与模块 API 行为。
    作用：WASM 能力指纹；构造行为差异反映引擎版本。
  • svg —— SVG getBBox/getScreenCTM 渲染形状。
    作用：SVG 渲染引擎指纹。
  • domrect —— DOMRect.fromRect/toJSON 键集与 getClientRects 行为。
    作用：DOM 几何 API 指纹（引擎版本敏感）。
  • textmetrics —— 文本测量边界行为（零宽字符/Emoji/连字）。
    作用：文本引擎指纹：边界字符测量差异显著。
  • voices —— 语音合成声音列表（名称/语言/本地或远程）。
    作用：系统 TTS 声音集合指纹，设备级差异明显。
  • queryLies —— 10 核心接口的函数完整性逐项检查（toString 白名单/ownProps/描述符/栈帧）。
    作用：原生函数被包装或篡改时在此暴露；每项检查失败都是具体证据。
  • prototypeLies —— 40+ 接口原型链属性采集与 hashMini 基线。
    作用：原型面基线指纹；与已知扩展哈希比对识别浏览器扩展。
  • crossValidation —— plugins 与 mimeTypes 双向一致性验证。
    作用：插件集合结构异常（缺失/错配）暴露伪造。
  • phantomIframe —— 隐藏 iframe 隔离环境 12 项同款 API 对比。
    作用：主窗口与隔离环境的差异暴露扩展注入或环境伪装。
  • stability —— 双画布逐像素稳定性、双音频波形一致性、Math 期望值表。
    作用：每次渲染结果不同的画布/音频是噪声注入的直接证据；Math 输出偏差反映引擎异常。
  • timerPrecision —— 环境探测参数。
    作用：采集环境特征数据，用于指纹对照与一致性分析。

使用约束

1. 采集页面将采集您的浏览器环境/行为指纹并存储至共享数据库。该数据仅用于 风控研究对照分析，请勿在包含隐私信息的环境中访问。 2. 采集数据在本平台内公开共享。将数据带出平台时，须遵守 restricted-local 数据分级纪律：环境数据仅允许输出脱敏摘要（组件名、哈希、维度计数）； 行为轨迹与击键间隔原值不得输出，仅允许信号判定摘要与统计值。 3. 采集脚本由平台管理员编写与维护，请勿引入第三方来源代码。
